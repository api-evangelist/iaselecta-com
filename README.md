IA Selecta is a Spanish-language platform that indexes 256 AI tools across 12 categories, providing real launch dates and verified revenue data via Stripe when creators connect their products. The site offers pricing information, guides, a blog, and a submission portal for developers to list their AI solutions. It serves as a comprehensive directory for AI enthusiasts and businesses seeking up-to-date tool information.

**Areas:** AI · Directory · Tools · Spanish · Platform · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for IA Selecta: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
